True Proxy 0.2.0

- Автоматическая проверка GitHub Releases при запуске и каждые 6 часов.
- Уведомление о новой версии и кнопка обновления в интерфейсе.
- Проверка SHA-256, установка после ручной паузы, перезапуск и восстановление EXE при ошибке запуска.
- Переключатель автоматической проверки и ручная проверка в настройках.
- Темный нативный интерфейс, редактор списков и выбор запущенных процессов.
- Раскрываемые соединения по процессам, сохранение паузы, логотип и индикатор в трее.
- Исправлена идентификация System (PID 4), которая мешала применению правил к SMB.

Windows x64. WinDivert встроен в EXE. Обычный запуск запрашивает UAC.
DNS остается системным. Сетевой backend экспериментальный; сквозная совместимость
с VPN, SMB и играми требует проверки в пользовательской или изолированной среде.
