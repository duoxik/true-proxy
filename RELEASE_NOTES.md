True Proxy 0.4.0

- Импорт и экспорт конфигурации в настройках: переносимый JSON с прокси, правилами и маршрутом по умолчанию.
- Экспорт копирует JSON в буфер обмена и показывает уведомление. Пароли SOCKS включаются в открытом виде; в локальном профиле они остаются защищены Windows DPAPI.
- Редактор импорта поддерживает вставку, подсветку синтаксиса, форматирование и проверку структуры, версии, значений и ссылок на прокси. Ошибка импорта не меняет текущую конфигурацию.
- Правила, прокси и маршрут по умолчанию можно сохранять при работающей маршрутизации. Сохранение не останавливает backend.
- После сохранения доступны «Применить позже» и «Перезапустить прокси». При отсрочке остаётся оранжевое уведомление, прежняя конфигурация продолжает действовать до перезапуска.
- Перезапуск выполняется только по нажатию, с остановкой старого backend перед запуском нового. Текущие прокси-соединения закрываются; перехват временно останавливается.
- Исправлены пустые промежутки в коротких формах и выравнивание кнопок со списками, включая редактор правил и выбор процессов.
- Убраны лишние подписи и счётчики; блок маршрута по умолчанию стал компактнее.

Импорт заменяет правила и прокси, сохраняя состояние включённости, автозапуск и настройки обновлений. Максимальный размер JSON — 2 МиБ.

Windows x64. WinDivert встроен в EXE. DNS остаётся системным.
Backend экспериментальный; сквозные проверки перехвата требуют изолированной среды.
