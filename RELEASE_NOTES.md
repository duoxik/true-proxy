True Proxy 0.12.13

- Dashboard shows session status, traffic, and connection counts in the new light and dark themes. General settings uses the same cards, buttons, and switches. Both themes use the lime accent. The existing sidebar layout is preserved.
- After changing active routing rules or proxies, use **Restart** in the floating notification. Closing the toast keeps the action under the bell. Restart briefly interrupts interception and closes current proxy connections.
- Appearance controls the transparency and blur of notifications and the notification center.
- The Xray profile port selector uses a neutral outline. Xray sends queries to the configured Tunnel DNS resolver directly from the device. Profiles using that resolver no longer need a DNS exit selection.

Windows x64. WinDivert is bundled in the executable. The interception backend is experimental.
