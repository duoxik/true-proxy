True Proxy 0.2.2

- Исправлен отсутствующий значок трея после автозапуска при входе в Windows.
- Повторная регистрация значка, если Проводник еще не готов; восстановление после его перезапуска.
- Таймер восстановления отключается после успешной регистрации.
- Повторный запуск EXE открывает окно уже работающего экземпляра.
- Сохранены ручная пауза, зеленый/красный статус и меню трея.
- Добавлены проверки скрытого запуска и восстановления без перезапуска Проводника пользователя.

Windows x64. WinDivert встроен в EXE. Обычный запуск запрашивает UAC.
DNS остается системным. Сетевой backend экспериментальный.
