True Proxy 0.12.6

- Fixed vertical alignment of Dashboard metrics and routing-rule badges.
- Removed the Overview / Dashboard breadcrumb.
- Unified page headers and top action buttons across Dashboard, Rules, Proxies, Connections, Settings, Logs, and X-RAY using shared native Slint components.
- CI and release workflows now share the static-CRT dependency cache from main. Added a verification mode that builds and checks release packages without publishing.

Windows x64. WinDivert is bundled in the executable. The interception backend is experimental.
