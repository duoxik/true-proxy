True Proxy 0.10.1

- Connections shows icons from local application executables. Icons are loaded in the background and cached. The generic icon appears when an executable icon is unavailable.
- Fallback shows a colored route badge and an edit button. Local and Fallback display lock icons in the Rules list.
- Enabled switches use the same purple accent throughout the interface.

Windows x64. WinDivert is bundled in the executable. Windows resolves DNS. The interception backend is experimental.
