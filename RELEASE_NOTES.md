True Proxy 0.12.2

- Rules follow the pointer while dragging. Dropping a rule saves its new position.
- The restart prompt disappears when the saved routing configuration matches the running configuration again.
- Removed the Routing Rules breadcrumb and the outline that appeared after clicking a sidebar item.
- The native Windows 11 title bar matches the dark sidebar. The main window allows screen capture.

Windows x64. WinDivert is bundled in the executable. The interception backend is experimental.
