True Proxy 0.2.1

- Главная страница: большая кнопка запуска и остановки, таймер текущей сессии.
- Убраны приветственный баннер, быстрый старт и лишние подписи.
- Автозапуск при входе в Windows с запуском в трей и сохранением ручной паузы.
- Маршрут по умолчанию закреплен в конце списка правил; тумблеры правил — в списке.
- Единое меню «+» для ручного ввода, запущенных процессов и выбора EXE.
- Домены, IP и порты — раскрываемые дополнительные условия с сохранением значений.
- Проверка соединения в форме прокси без сохранения введенных данных.
- Цветные статусы TCP/UDP и автоматическая проверка каждые 30 секунд.

Windows x64. WinDivert встроен в EXE. Обычный запуск запрашивает UAC.
DNS остается системным. Сетевой backend экспериментальный; сквозная совместимость
с VPN, SMB и играми требует проверки в пользовательской или изолированной среде.
