True Proxy 0.6.0

- Компактная панель 420×720 открывается над значком в трее и скрывается при клике снаружи. Обзор, правила, прокси, настройки и формы редактирования доступны внутри панели.
- «Соединения» открываются отдельным окном. Добавлены поиск по имени процесса и фильтры по маршрутам и статусам. По умолчанию видны незавершённые соединения. Журнал начинает сбор при открытии окна и очищается при закрытии или сворачивании.
- Встроенное правило «Локальная сеть» всегда стоит первым. Оно направляет базовые частные, link-local и loopback адреса напрямую и не редактируется. Пользовательские правила в существующих профилях сохраняются.
- Маршрут по умолчанию сохраняется при выборе в одном меню. Пункт «Прокси» раскрывает список SOCKS5-подключений. При работающей маршрутизации интерфейс предлагает применить изменения при перезапуске.
- Условия правил редактируются отдельными строками. «Добавить» создаёт пустую строку, а для приложений открывает выбор ручного ввода, списка процессов или пути к EXE.
- Проверка SOCKS5 запускается вручную и показывает результат уведомлением. Периодический опрос прокси отключён.

Windows x64. WinDivert встроен в EXE. DNS использует системный резолвер Windows. Сетевой backend остаётся экспериментальным.
