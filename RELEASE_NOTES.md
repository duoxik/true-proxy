True Proxy 0.12.13

- The redesigned Dashboard shows routing status, session time and traffic in both themes. General now groups theme selection, surface effects, updates and startup settings.
- On supported Windows 11 PCs, the sidebar defaults to **Acrylic** with **30% transparency** and **Frost level 32/32**. Set frost to zero for a sharp view through the sidebar, or choose **Mica** for a wallpaper tint. Sidebar and notification settings are independent. Existing choices carry over.
- Routing restarts, Xray restarts and app updates now appear as floating notifications. The bell keeps pending actions after you dismiss a notification. **What's new** shows the offered version's release notes before you download it.
- In **Modules**, use **Check all** to check Xray-core and hpwnr together. Each module shows its version, update status and download progress.
- In **X-RAY → Profiles**, the port selector keeps the full port number visible beside long names. For SOCKS5 clients that pass a domain name to Xray, Xray now queries the configured DNS resolver directly from the device. Your resolver address carries over and you no longer need to choose a VPN profile for DNS.

Windows x64. WinDivert is bundled in the executable. The interception backend is experimental.
