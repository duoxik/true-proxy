# True Proxy

**Русский** · [English](README.en.md)

Маршрутизация TCP и UDP отдельных приложений через SOCKS5 на Windows. Направьте браузер, игру и рабочие программы через разные прокси и управляйте маршрутами из одного окна.

**[Скачать для Windows x64](https://github.com/duoxik/true-proxy/releases/latest)** · [Что нового](RELEASE_NOTES.md) · [Руководство](docs/guide.md)

![True Proxy Dashboard с графиком трафика, прокси и правилами](docs/screenshots/dashboard-demo.png)

*Демо: адрес прокси, локация и трафик заданы для примера.*

## Быстрый старт

1. Скачайте `TrueProxy-windows-x64.zip`, распакуйте архив и запустите `TrueProxy.exe`. Windows запросит права администратора для перехвата трафика.
2. В **Proxy → Proxies** добавьте SOCKS5-сервер и проверьте его кнопкой **Test**. Для UDP серверу нужна поддержка `UDP ASSOCIATE`.
3. В **Proxy → Rules** создайте правило, выберите приложение и нужный прокси. Проверьте **Fallback** — маршрут для трафика, который не совпал ни с одним правилом.
4. На **Dashboard** нажмите **Start Routing**, если маршрутизация на паузе. Крестик окна оставляет приложение в трее. **Exit** в меню трея останавливает перехват.

При изменении правил во время работы кнопка **Restart** применяет настройки и завершает текущие прокси-соединения.

## Что важно знать

- **Маршрутизация.** Локальные сети идут напрямую. Для остального трафика действует первое совпавшее правило, затем **Fallback**. Доменные правила зависят от наблюдаемых ответов DNS.
- **DNS.** Обычные DNS-запросы разрешает Windows. DoH и DoT следуют правилам приложения.
- **Конфигурация.** Windows защищает SOCKS5-пароли в локальном профиле. Экспорт в JSON включает их в открытом виде.
- **Статус.** Перехват WinDivert экспериментальный. Сквозные проверки TCP, UDP, IPv6 и совместимости с VPN ещё нужны. [Подробные ограничения](docs/guide.md#ограничения).
